# Capture calibration

Choose window capture first. Restore a minimized game, try borderless mode, or select its display if capture fails. Display capture includes whatever is visible on that monitor.

Drag a tight dialogue rectangle containing all text rows with a small margin. Exclude the nameplate, buttons and advance arrow. Drag the separate nameplate rectangle around the name text. Test recognition on at least two lines. Save the profile. Coordinates are normalized against captured pixels, keyed by source type, title and frame resolution. Changing resolution pauses listening for a calibration check.

Start with 3 frames per second and 450 ms stabilization. Increase stability if the game types slowly. OCR cannot distinguish an unusually long mid-sentence pause from completion solely from identical frames. Lower contrast if thin lettering disappears. A missing or low-confidence name uses the narrator. Menu filtering is heuristic. Pause on non-dialogue screens if needed.

Windows gameplay acceptance remains necessary for the English Steam trilogy, especially menus, effects, multi-monitor DPI changes, typewriter timing, nameless dialogue, repeated text, rapid advancement and audio balance with the game.
